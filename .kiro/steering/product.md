# Product Overview

SaSvoth is a decentralized voting and governance platform built on blockchain technology. The application enables users to:

- Submit and vote on ideas/proposals
- Participate in polls using MACI (Minimal Anti-Collusion Infrastructure) for privacy-preserving voting
- Earn and manage voice credits for voting power
- Claim rewards based on participation
- Authenticate via OAuth (Google, GitHub) or Web3 wallets

The platform uses zero-knowledge proofs (ZK-SNARKs) via Circom circuits to ensure vote privacy and prevent collusion while maintaining verifiability. It integrates with IPFS for decentralized storage and Ethereum smart contracts for on-chain governance.

## Key Features

- Privacy-preserving voting with MACI protocol
- Zero-knowledge proof generation for vote commitments
- Web3 wallet integration (Wagmi)
- OAuth authentication support
- IPFS-based decentralized storage
- Smart contract integration for rewards and token claiming
- Voice credit system for weighted voting
